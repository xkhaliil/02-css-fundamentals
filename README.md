# Lecture 2 — CSS fundamentals

Exercises and playgrounds for the CSS lecture: connecting styles, anatomy of a
rule, selectors, the cascade and specificity, core properties and units.

Open `index.html` in a browser for the full list. Everything is static HTML —
serve the folder with any local server (e.g. `npx live-server`) so the live
editors and checks work.

## Start here

1. Download `project/starter.zip`, extract it, open the folder in your editor.
2. Link `css/style.css` from `index.html` (Exercise 1).
3. Work through the exercises in order.

## Playgrounds

`playgrounds/` — selector tester, `:nth-child()`, specificity calculator,
colour + contrast checker, box model, units. `project/showcase/` is the same
HTML dressed in four stylesheets (swiss, brutal, neon, zine) — read their CSS
and steal techniques. `cheatsheet.html` prints on one A4 page.
