Everything from Lecture 2, condensed. Print it, stick it next to your screen.

1 Connect

<link rel="stylesheet" href="css/style.css">

Goes in <head>. Path starts at the HTML file. ../ = up a folder. Lowercase file names.

Also: <style>…</style> (one page), style="" (one element).

Nothing happens? Network tab → 404? Styles panel → rule there? Crossed out?

2 Anatomy

/* selector   declaration block */
.vendor-card h3 {
  color: tomato;     /* declaration */
  font-size: 1.5rem; /* property: value; */
}

Invalid declaration → that line skipped. Invalid selector → whole rule skipped. No error messages: DevTools shows ⚠.

4 The cascade

  1. Origin & importance — author > user > browser; !important flips it
  2. Inline style="" — beats selectors
  3. Layers — later @layer wins; unlayered beats all
  4. Specificity — see below
  5. Order — later wins

Each round only runs on a tie. Inherited values lose to any direct rule.

5 Specificity (ID, CLASS, TYPE)

ID#x
CLASS.x [x] :hover
TYPEp ::before
zero* combinators :where()
borrowed:is() :not() :has() = strongest arg

#nav .item a:hover = (1, 2, 1). Compare left to right: (1,0,0) beats (0,99,0).

6 Habits

  • Style with classes, 1–2 per selector.
  • No ids in CSS. !important only for code you can't edit.
  • File order: reset → base → components → tweaks.
*, *::before, *::after { box-sizing: border-box; }
button, input, select, textarea { font: inherit; }

7 Colour

tomato = #ff6347 = rgb(255 99 71) = hsl(9 100% 64%)

Transparency: rgb(255 99 71 / 50%). HSL: keep hue, change lightness for shades.

Contrast: ≥ 4.5 : 1 text, ≥ 3 : 1 large headings.

8 Box model

content → padding → border → margin

content-box: visible width = width + padding + border. border-box: visible width = width.

Shorthand clockwise: margin: T R B L, margin: V H, margin: 0 auto centres. Vertical margins collapse.

10 Custom properties

11 Web fonts & at-rules

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Bricolage+Grotesque&display=swap">

Then font-family: "Bricolage Grotesque", system-ui, sans-serif; Max two families.

@media when · @import another file · @font-face a font · @layer order · @keyframes animation

12 Block vs inline

Block (p, h1, li, section, div): full width, stacks. Inline (a, span, strong): flows like text — width, height and vertical margin ignored. display: inline-block: both.
