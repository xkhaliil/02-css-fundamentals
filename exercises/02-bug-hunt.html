Bug hunt

Seven bugs. Zero error messages.

This vendor card should look finished. It doesn't, because seven small mistakes are hiding in the CSS. The browser won't complain — it quietly skips what it can't read. Fix the code until every pill below turns green.

Stuck?

Use the real DevTools. Right-click the preview → Inspect. In the Styles panel, a declaration the browser couldn't understand is struck through with a ⚠ warning icon. A rule that's missing completely has a broken selector.

Still stuck? The seven bug types

A missing semicolon · a missing unit · a misspelled property · a space inside a number · a comma where none belongs · an invalid keyword · a typo in a pseudo-class.
