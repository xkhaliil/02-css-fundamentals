Units

Relative to what?

Every relative unit is a question: relative to what? Change the browser font size, the parent font size and the viewport width, and watch which bars react.

Rules of thumb

  • rem for font sizes — respects the reader's browser setting.
  • em for padding that should grow with its text (buttons, tags).
  • px for borders and hairlines.
  • % / vw for widths that follow the container or screen.
  • ch for readable line length: max-width: 65ch.
